# Page d’accueil EduPilot Bénin

Page statique autonome, publiée à la racine du site GitHub Pages du dépôt `osnyl/edupilot-benin`.

- `index.html` : contenu et structure de la page.
- `styles.css` : styles responsive.
- `assets/hero-classroom.webp` : illustration originale du projet.
- `favicon.svg` : icône de page.

La page n’embarque pas de données d’élèves, formulaire, compte, backend ni base de données. Pour modifier le texte, éditer `index.html` ; pour l’apparence, éditer `styles.css`.
