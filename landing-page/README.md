# Site EduPilot Bénin

Site statique autonome prévu pour GitHub Pages, synchronisé avec le prototype EduPilot.

- `index.html` : page d’accueil et accès « Se connecter » / « Créer un compte ».
- `login.html` et `login.js` : page de démonstration avec les rôles Directeur, Secrétaire et Censeur.
- `styles.css` : styles responsives des deux pages.
- `assets/hero-classroom.webp` : illustration locale, servie avec le site.

Les parcours de connexion et de création de compte sont fictifs : aucun mot de passe n’est demandé, aucune donnée n’est transmise ou enregistrée, et aucun backend n’est utilisé.
